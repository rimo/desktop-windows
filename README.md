# Rimo Desktop (Windows)

**Rimo Desktop (Windows 版) の公式配布リポジトリです。** アプリのバイナリは [Releases](https://github.com/rimo/desktop-windows/releases) からのみ取得してください。macOS 版は [rimo/desktop](https://github.com/rimo/desktop) で配布しています。

Rimo Desktop は、会議ボットを使わずにローカルで音声・画面を録音し、[Rimo](https://rimo.app) にアップロードして文字起こしするデスクトップアプリです。会議中のリアルタイム文字起こしを手元に表示します。

## インストール

1. [最新リリース](https://github.com/rimo/desktop-windows/releases/latest)を開きます。
2. `.exe` のインストーラーをダウンロードします。
3. インストーラーを実行し、画面の指示に従ってインストールします。

アプリは自動アップデートに対応しています(新しいバージョンは自動で適用されます)。

# Rimo Desktop for Windows (English)

**This is the official distribution repository for Rimo Desktop on Windows.** Download the app binaries only from [Releases](https://github.com/rimo/desktop-windows/releases). The macOS build is distributed from [rimo/desktop](https://github.com/rimo/desktop).

Rimo Desktop records audio and screen locally — no meeting bot required — and uploads to [Rimo](https://rimo.app) for transcription, with real-time transcription shown during meetings.

## Install

1. Open the [latest release](https://github.com/rimo/desktop-windows/releases/latest).
2. Download the `.exe` installer.
3. Run the installer and follow the prompts.

The app updates itself automatically.
